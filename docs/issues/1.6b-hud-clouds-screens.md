# 1.6b Clouds, welcome screen and win screens (proposed split of 1.6)

**Size:** M · **Area:** `gg_client` · **Depends on:** 1.6a

## Goal

Everything v1 drew outside the round itself.

## What to build

- Clouds: 16 clouds from `data/images/clouds/`, drawn at 8× size, drifting right at 0.05–0.25 px per frame. They are cosmetic, so they live in the renderer and may use `random`.
- Welcome screen before the first round (`data/images/welcome.png`), with the slow up-and-down bob v1 had. Enter starts.
- Win screen after `snapshot["phase"] == "round_over"`: `P1.png` or `P2.png` according to `snapshot["winner"]`; show plain text for a draw.

## Done when

- [ ] Start → welcome → Enter → round → win screen → Enter → new round
- [ ] The winner shown matches `snapshot["winner"]`
- [ ] No game rules in the client: it only reads the snapshot
