# 2.7 (first part) Prove the pygbag build runs on a static host

**Size:** S · **Area:** web build, CI · **Read first:** `docs/spikes/pygbag.md`

## Why

In the spike, a plain static server on localhost gave a blank grey page: the page asked for `/cdn/cp312/pygame_ce-…whl` on the same host and got a 404. pygbag's own test server hides this by proxying. We do not yet know what happens on GitHub Pages.

## What to do

- [ ] Build the spike (`./spikes/pygbag/build.sh`) and publish `spikes/pygbag/build/web` to GitHub Pages from a branch or a fork
- [ ] Open it in Chrome, Firefox and Safari; record whether it starts and the load time
- [ ] If it fails: find the pygbag option or template change that points wheels at the CDN, or self-host the runtime (about 22 MB)
- [ ] Write the result and the chosen approach (CDN or self-hosted) at the end of `docs/spikes/pygbag.md`

## Done when

A public URL shows the spike running in three browsers, and the write-up says how.
